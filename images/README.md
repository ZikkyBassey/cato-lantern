# CAT O'LANTERN Images

This folder contains the images for the website.

## Required Images

1. **cat-o-lantern-hero.png** - The cat face with pumpkin head (smaller image on the right)
   - Used in the hero section
   - Should be roughly square format
   - Recommended size: 400x400px or larger

2. **cat-o-lantern-full.png** - The full pumpkin cat with moon background (large dramatic image)
   - Used in the featured image showcase section
   - Recommended size: 800x600px or larger

## How to Add Images

### Option 1: Use Your Own Images
Save your images in this folder with these exact filenames:
- `cat-o-lantern-hero.png`
- `cat-o-lantern-full.png`

### Option 2: Download from Chat
You can right-click on the images in your chat and "Save Image As..." to download them, then move them to this folder.

Once the images are saved, refresh http://localhost:8000 in your browser to see them appear on the website!
